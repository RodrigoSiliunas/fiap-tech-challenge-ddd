# Documentação DDD — Tech Challenge Fase 1

Board no Miro: [https://miro.com/app/board/uXjVESOKEKE=/](https://miro.com/app/board/uXjVESOKEKE=/)

O board reúne o Event Storming dos três fluxos, o big picture, os subdomínios, o mapa de contexto, os agregados, a máquina de estados, a arquitetura, o domain storytelling, o glossário e a relação com o código. Os PDFs e o PNG desta pasta são o export desse conteúdo.

| Arquivo | Descrição |
|---------|-----------|
| `linguagem-ubiqua.md` | Glossário (termo, definição, contexto, nome no código) |
| `event-storming.md` | Event Storming dos 3 fluxos (texto + mermaid) |
| `event-storming.pdf` | Export do Event Storming do board: legenda, 3 fluxos e big picture |
| `event-storming.png` | Os 3 fluxos em sticky notes, como no board |
| `diagramas.md` | Subdomínios, context map, agregados, FSM, arquitetura |
| `diagramas.pdf` | Export dos diagramas do board, com a relação com o código e o glossário |
| `domain-storytelling/` | Domain Storytelling (`.egn` do Egon, sentenças, SVG e PNG) |
| `mapeamento-codigo.md` | Relação entre estes artefatos e o código em `backend/app/` |

Convenção de cores: Aula 06 FIAP. Domínio em português no código (ver glossário).

Os `.egn` de `domain-storytelling/` importam em [egon.io](https://egon.io/app/).
